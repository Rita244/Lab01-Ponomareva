ПР1. Ответы на контрольные вопросы
1. C# — компилируемый язык. Сначала компилятор проверяет весь код, и если есть ошибка — программа вообще не запустится.

Python — интерпретируемый язык. Код выполняется по строчкам, поэтому ошибка обнаружится только тогда, когда программа дойдёт до проблемного места.

2. Два шага:

1. Собирает проект (компилирует код) — это называется build.
2. Запускает готовую программу.

3. · bin/ — готовые скомпилированные файлы.
· obj/ — промежуточные файлы, создаваемые при сборке.

Это не исходный код, а результат сборки. Их можно легко создать заново командой dotnet run, поэтому в Git они не нужны. Чтобы Git их игнорировал, используется файл .gitignore.

4. · git commit — сохраняет изменения у тебя на компьютере (в локальном репозитории).
· git push — отправляет эти сохранённые коммиты на GitHub.

Порядок: сначала commit, потом push.

5. · Конкатенация: "Имя: " + name — склеиваем строки через +.
· Интерполяция: $"Имя: {name}" — вставляем переменные прямо в строку.

6. Если оба числа — int, результат тоже будет int, а дробная часть отбрасывается (не округляется).
10 / 3 даст 3, а не 3.33.

const — это постоянное значение, которое задаётся один раз и не может меняться. Попытка изменить его вызовет ошибку компиляции.
Пример:
const int MonthsInSemester = 4;

Удобно, когда значение точно фиксировано (например, число месяцев в семестре для расчёта).

8. Top-level statements vs class Program { static void Main() }
Top-level statements — можно писать код сразу в Program.cs, без класса и метода Main. Компилятор сам создаёт нужную структуру. Код короче и проще.
  Console.WriteLine("Hello, World!");
